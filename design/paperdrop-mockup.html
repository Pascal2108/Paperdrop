Paperdrop web UI mockup

The same page at desktop and phone width. It's one HTML file with inline CSS and a few lines of JS, system fonts, no framework, and no external requests, so it can ship as-is from the container. Everything below is clickable.

What changed from today's page

  • On phones, Scan with camera opens the camera directly (capture="environment"), next to Choose files.
  • Files waiting to be compressed show as a list, so you can drop one before compressing.
  • Document titles are editable before upload; that's the title Paperless gets.
  • Upload all sits in a bar at the bottom on phones, in thumb reach.

New, small additions

  • Compression strength: Light, Balanced, Strong.
  • Sent to Paperless shows the last few uploads with their consume status, read from the Paperless task API.

Keeping it light

No web fonts, no icon font, no build step. Icons are inline SVG symbols, the logo is the existing Paperdrop icon. The layout switches with one container query at 820 px, so there is a single template for every screen size.
